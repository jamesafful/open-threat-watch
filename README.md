# OpenThreatWatch 🔐

**An open-source platform for real-time cybersecurity threat analysis using machine learning.**

## 🚀 Features
- Live CVE ingestion from NVD
- ML-based severity classification
- MITRE ATT&CK mapping
- Interactive dashboard with trends, filters, and insights
- Weekly threat intelligence report generation

## 📦 Tech Stack
- Python, Flask, Plotly Dash
- Scikit-learn, TF-IDF, SHAP
- NVD API, MITRE ATT&CK STIX

## 🔍 Use Case
Empowering security researchers, educators, and policy analysts with real-time, explainable insights into emerging threats.
